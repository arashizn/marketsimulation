# Market Simulation 投资银行模拟交易

运行：双击 `start.bat`（或 `python server.py [端口]`），无需安装任何依赖（仅需 Python 3）。
- 老师：浏览器打开 http://localhost:8000 ，“管理员登录”，默认密码 `admin`（在“规则设置”里修改）。
- 学生：同一局域网访问启动时打印的地址，用“小组口令 + 姓名”登录。
  - 全新启动（还没有任何小组）时，系统会自动建一个“第1组”，默认口令为 `GROUP1`（不分大小写）；姓名没有预设，随便填，会自动加入该组。
  - 其他小组的口令在老师创建小组时随机生成，可在“小组管理”里修改。
  - 想限制只有名单内成员能登录：在“小组管理”里填好成员，并在“规则设置”里关闭“允许学生自助加入”。
- 数据保存在 `data/state.json`（含管理员密码和口令，已加入 `.gitignore`，请勿提交到 GitHub）。

## 老师流程
1. 小组管理：批量创建 N 组（组数、每组人数不限），把口令发给各组。
2. 资产与价格：默认 20 只港股 + 黄金 + 国债，价格为**随机演示价格**；真实使用请下载 CSV 模板，填入真实周收盘价后导入。
3. 规则设置：所有参数均可在后台调整。
4. 每周：学生下单 → 老师确认该周价格已录入 → “结算本周”（可撤销最近一次）。

## 会计结账（Accounting Close）
每周结算后，学生在“会计结账”页完成：新买入资产的会计分类（FVTPL / FVOCI / AC / INVENTORY）及理由、减值/跌价准备、放款的预期信用损失，再写会计说明并提交。系统自动生成分录、资产负债表、利润表、其他综合收益表，并与排行榜净资产对账。
- 必须按周顺序提交；老师在“会计作业”页评分（0-100）或退回修改；评分后学生不能再改。
- 分类不合适（如股票选 AC）不阻止提交，只在“系统提示”里警告，由老师评分时参考。
- 规则设置里可关闭该功能、设置权重（默认 25%），或开启“未提交上周会计结账不能下单”。
- 旧的 data/state.json 可直接加载，但旧数据缺少“现金利息记录”，已结算周的会计对账会有提示。

## 部署到 Render（公网访问）
1. 把代码推送到 GitHub（`data/` 已被忽略，不会上传）。
2. 登录 https://render.com → New → **Blueprint**，选择本仓库，Render 会读取 `render.yaml`。
3. 在环境变量里填写 **`ADMIN_PASSWORD`**（管理员密码，不要写进仓库）。每次启动都会用它覆盖。
4. 部署完成后，把 Render 给的 `https://xxx.onrender.com` 发给学生，用“小组口令 + 姓名”登录。

注意：
- 数据保存在持久化磁盘（`DATA_DIR=/var/data`）。**免费实例没有磁盘，重启后小组和成绩会丢**，所以 `render.yaml` 用了付费的 starter 实例；课堂短期使用可自行改成 `free`，但每次睡眠/重启都会清空。
- 本程序只适合单实例运行（数据在内存和单个文件里），不要开多个实例。
- 登录有简单限流（同一 IP 5 分钟内失败 8 次会被暂时拦截），但没有为大规模公网使用做安全加固，建议仅在课程期间开放。
- 环境变量：`PORT`（端口，Render 自动提供）、`ADMIN_PASSWORD`、`DATA_DIR`。

## 使用 PostgreSQL 存储（可选）
默认把数据存在 `data/state.json`。设置环境变量 **`DATABASE_URL`**（如 `postgresql://user:pass@host:5432/dbname`）后，改为存入 PostgreSQL 的 `app_state` 表（整个状态一行 JSONB，另一行保存“撤销结算”快照）。
- 先 `pip install -r requirements.txt`（只有用数据库时才需要驱动；文件模式仍然零依赖）。
- 数据库为空且本地存在 `data/state.json` 时，启动会自动导入，旧数据不丢。
- 断线会自动重连。仍然只能单实例运行：状态在内存里，多实例会互相覆盖。
- Render 上可以在同一账号里新建 PostgreSQL，把 Internal Database URL 填到 `DATABASE_URL`；这样不再需要付费磁盘，但数据库本身免费档有期限，长期使用请选付费档。**不要把 `DATABASE_URL` 写进仓库。**
- 备份：`pg_dump "$DATABASE_URL" | gzip > backup.sql.gz`。
